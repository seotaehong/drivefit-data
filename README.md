# drivefit-traffic (공개 배포용)

길핏(DriveFit) 앱이 읽는 고속도로 소통(정체) 요약 파일 `latest.json` 하나만 배포하는 저장소입니다.

- 내용: 남해선 산인JC→창원JC 두 갈래 구간의 구간별 소통 등급·속도(약 4KB).
- 갱신: 수집 PC가 5분 간격으로 받아 바뀌었을 때만 올립니다. PC가 꺼지면 갱신이 멈춥니다.
- 시각: 앱은 파일 안의 `stdStamp`(원자료 기준 시각)로 자료 나이를 계산합니다. 15분이 넘은 자료는 "정체 정보 없음"으로 처리합니다.
- 출처: 고속도로 소통 정보 — 한국도로공사 공공데이터(data.ex.co.kr, 실시간 소통 정보). 이용 조건은 한국도로공사 공공데이터 이용정책을 따릅니다.
- API 키나 개인 정보는 들어 있지 않습니다.
